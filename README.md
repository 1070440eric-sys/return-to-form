# Return to Form｜異界

一款會死很多次的文字遊戲。死了會「返回」，但你記得的事會留下來。

## 怎麼玩

用瀏覽器打開 `index.html` 就能玩，不用安裝任何東西。

## 目前的內容

- 第一段：從被傳送到第一次分岔
- 種田線：完整，結局是世界結束
- 假主線、真路線：只有入口，還沒寫

## 怎麼改劇情

劇情全部在 `js/story.js`，其他檔案不用動。

每個場景長這樣：

```js
s2: {
  title: '村子',
  text: ['第一段文字。', '第二段文字。'],
  choices: [
    { label: '留下來幫忙', to: 's3' },
    { label: '問去城裡的路', to: 's4' }
  ]
}
```

選項可以加的東西：

| 寫法 | 效果 |
| --- | --- |
| `learn: ['k_xxx']` | 記下一條線索。死了也留著 |
| `set: ['st_xxx']` | 記下這一輪發生的事。返回就消失 |
| `needs: ['k_xxx']` | 有這條線索或狀態，選項才會出現 |
| `hideIf: ['k_xxx']` | 有這條線索或狀態，選項就不出現 |

場景可以加的東西：

| 寫法 | 效果 |
| --- | --- |
| `death: true` | 死亡場景。按「返回」回到做出致命選擇的地方 |
| `worldEnd: true` | 世界結束。按「返回」回到開場，線索保留 |
| `stub: true` | 還沒寫完的路線 |
| `learn` / `set` | 一進入這個場景就記下 |

新的線索要先在檔案上方的 `clues` 加一行，新的狀態加在 `states`。

貴族的名字還沒定，全檔用 `{noble}` 代替，改 `noble:` 那一行就會全部換掉。

## 改完之後檢查

```
node tools/check.js
```

它會找出指到不存在場景的選項、走不到的場景、沒定義的線索。

## 檔案

```
index.html       頁面
css/style.css    外觀
js/story.js      劇情（主要改這個）
js/engine.js     引擎
tools/check.js   劇情檢查工具
```
